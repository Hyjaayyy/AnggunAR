# Foto galeri

Tambahkan foto berizin sebagai `[nama-unik].webp`, lalu daftarkan pada `src/data/gallery.ts`. Rekomendasi lebar 1600–2400 px, kompres WebP, caption dan alt ID/EN yang menjelaskan konteks foto sebenarnya. Jangan menyebut dokumentasi pelanggan tanpa dasar.

Status published, catatan izin, dan file yang tersedia diperlukan sebelum foto tampil. Jumlah foto fleksibel; file hilang dilewati. Semua file public tetap dapat diakses langsung, termasuk milik draft. Lihat `docs/GALLERY.md`.
