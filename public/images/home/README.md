# Poster video homepage

Masukkan poster resmi sebagai `batam-cinematic-poster.webp` dalam folder ini. Gunakan komposisi 16:9 yang sesuai dengan video. Poster bersifat opsional; tanpa poster digunakan fallback CSS.

Video berada di `public/videos/home/batam-cinematic.mp4`. Build ulang production setelah mengganti aset. Panduan lengkap: `docs/HOME_VIDEO.md`.
