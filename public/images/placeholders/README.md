# Ilustrasi placeholder Phase 2

Ketiga SVG dibuat khusus untuk proyek ini sebagai ilustrasi vektor konsep, tanpa foto pihak ketiga. Bukan foto lokasi, peta, representasi topografi akurat, atau dokumentasi perjalanan perusahaan. Visual jembatan hanya ilustrasi bertema Barelang.

Label placeholder harus tetap terlihat hingga aset diganti dengan foto resmi atau foto berlisensi yang telah disetujui. Foto pengganti harus memiliki sumber, izin penggunaan, alt text sesuai gambar, serta dimensi yang dioptimalkan. Gunakan next/image untuk foto raster; SVG lokal saat ini memakai next/image dengan perilaku unoptimized bawaan SVG.
